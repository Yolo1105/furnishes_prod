# Production domain map

Source: the legacy production archive (see `docs/PROVENANCE.md`). This is an
inventory only: no schema, API route, or service code is copied or connected
until a phase in `docs/ROADMAP.md` deliberately ports it.

Evidence: ~100 API route groups under `app/api/**`, a Prisma schema with ~90
models and ~50 enums under `prisma/schema.prisma`, plus `lib/`, `contexts/`,
`hooks/`, and `__tests__/` directories.
